# LoanFlow

**LoanFlow** is a fictional consumer-loan application built as a production-style React portfolio project.

The project is designed to demonstrate modern frontend engineering around a realistic fintech flow: loan configuration, multi-step forms, validation, application state, API-style submission, automated testing and CI/CD.

> Portfolio project only. LoanFlow is not affiliated with or modeled as the UI of any real bank.

## Target stack

React 18 · TypeScript · Nx · React Router · TanStack Query · React Hook Form · Zod · Zustand · Vitest · Cypress · GitHub Actions

## Planned user flow

`Calculator → Loan configuration → Personal data → Income & expenses → Review → Submit → Application status`

## Portfolio role

LoanFlow is the main React project in my portfolio. It complements [Asteria Design System](https://github.com/Kamilla29/asteria-design-system), which focuses on design-token architecture across web and game interfaces.
